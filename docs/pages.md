# Pages — every HTML file in the repo

> Part of the GrowthKit AI docs set. Read [`CLAUDE.md`](../CLAUDE.md) first — it holds the non-negotiable mandates and conventions. This file is the deep reference for what each page is and contains. **If you add, remove, or materially change a page, update this file** (and follow the new-page checklist in [`docs/infrastructure.md`](infrastructure.md)).

All pages live at the repo root. Every public page is self-contained: inline `<style>` in `<head>`, shared `theme.css`/`theme.js`, duplicated topbar/footer (no templating). Dark-mode treatments referenced below are detailed in [`docs/design-system.md`](design-system.md).

## Public pages

- **`index.html`** (~2400 lines, ~100KB) — landing page: hero with "Specimen №01" plate, pinned editorial problem morph, engine schematic, three-step process, FAQ, closing CTA, footer. The only page that loads GSAP 3.13 + ScrollTrigger + Lenis (from jsDelivr). Head carries Organization + WebSite + WebPage + FAQPage JSON-LD. The FAQ pricing answer repeats `/pricing`'s numbers — keep them in sync. Directly under the hero sits an **"Integrated with" scrolling logo strip** (`.logos`, added 2026-07-09): a slow seamless-loop marquee of 8 monochrome brand lockups (Stripe, GitHub, Claude, ChatGPT, Notion, Slack, Linear, HubSpot), muted grayscale that brighten on hover, pausing on hover, static wrap under reduced-motion — same loop technique as `.marquee` (`@keyframes logos`, -50% translate on a duplicated track). Logos are inline SVG `<symbol>`s in a hidden sprite (`#gkl-*`), reused via `<use>`; dark tints them mint (`--neon-2`). **These are aspirational — only Claude is actually wired in; the `/four` dashboard shows the same logos tagged "Coming soon."** **The `#live` section is a sign-in CTA** (right after the strip) — "Create a free account / Log in", since the tool moved behind login to `/four` (2026-06-12; the embedded tool + advisor.css/js were removed from index). The hero "Try it free →" button points to `/signup`. See [`docs/auth.md`](auth.md). **The hero spec-plate is an `<a href="/specimen">`** (since 2026-06-12, not an aria-hidden `<aside>`): accessible name via `aria-label`, foot reads "view the specimen →", hover/focus draws an inset ring on `.spec-plate::before` (`::after` belongs to the dark scanline; ring z-index 5 > scanline 4; ring lives on the pseudo so the `.reveal` transition-delay can't lag the hover). The hero's secondary CTA also points at `/specimen` ("See a real teardown →") — don't point it back at `#engine`. Dark mode is the deepest on the site: live-console motion (CRT scanline sweep + terminal caret on the hero spec-plate, breathing engine nodes), marquee console rail, powered engine spine, glowing hero readouts, transparent problem-pin over the grid floor; **the dark topbar is solid black** (index-only override, 2026-07-05) and the **hero has WebGL neon threads** behind the headline (`threads.js`, mouse-reactive, dark-only, reduced-motion-off — see [`docs/design-system.md`](design-system.md)).
- **`waitlist.html`** — single-card signup form (Name, Work email, "wants updates" checkbox), morphs into a "You're on the list" success state. POSTs to the waitlist Apps Script — full plumbing + anti-spam in [`docs/forms-and-data.md`](forms-and-data.md). Emits `waitlist_signup` / `waitlist_error` analytics events. No footer (intentional).
- **`methodology.html`** — long-form pitch page: Hero → Mission → Marquee → 4 Pillars → 3 Steps → "Opinions we hold strongly" (5 tenets) → Final CTA. Dark mode at index parity: live hero-stats plate (CRT sweep + caret after "v0.4 · beta"), breathing process badges, glowing stat readouts, console-rail marquee.
- **`careers.html`** — Why-this-why-now → 4 perks → 2 role cards (Growth Intern → "Head of Growth" track, Marketing Intern → "CMO" track) → 3 application channels (email, company LinkedIn, Avi's LinkedIn). Head carries **JobPosting JSON-LD** for both roles (remote, GB/US, `validThrough` 2026-12-31 — **bump it or remove the postings when the roles close**, or Google flags them stale). Internship inquiries: `info@growthkitai.com`, subject `Internship — GrowthKit AI`.
- **`contact.html`** — hero with a `hero-meta` LED row ("Channels open · London · Remote · Reply — one business day") → two channel cards (email + LinkedIn) with ghost numerals 01/02 → meta strip. Dark mode is full manifesto-grade console: channel-online LEDs (offset so they don't blink in sync), phosphor `> ` address lines ending in a blinking terminal cursor, neon wireframe ghosts, scan-wash hovers, meta-strip `/` ticks.
- **`manifesto.html`** — founding document ("The market is knowable"): preamble with drop cap → 7 numbered articles (5 Believe / 2 Reject — expanded from methodology's tenets, reworded so the two pages don't read copy-pasted) → "Specimen №00" signature plate with blinking cursor → CTA. **This is the reference page for the neon-console dark mode** — when in doubt about the dark aesthetic, copy from here.
- **`security.html`** — honest security-posture page ("Security by subtraction"): 4 posture cards → architecture section with a mono terminal readout of the **actual** `vercel.json` security headers (**keep in sync if headers change**) → full data inventory → responsible disclosure (`info@growthkitai.com`, subject "Security — GrowthKit AI", 2-business-day ack, credit-no-bounty) → "What we don't claim" honesty block (**explicitly NOT SOC 2 / ISO 27001 — never add badge claims without Avi's sign-off**). Makes factual claims (MFA on founder accounts, named vendors, no payment data) — update the page if infrastructure changes; a wrong security page is worse than none. Promises a named thank-you for valid vulnerability reports — add the credit if one arrives.
- **`status.html`** — live status page. **Checks run client-side in the visitor's browser**: ① website/CDN via cache-busted fetch of `/logo-mark-64.png?ping=…`, ② waitlist intake via GET to the Apps Script `doGet` (expects `{ok:true,…}`) — both 9s timeouts with latency readouts; ③ engine row is a static "private beta" chip (no public endpoint). Master banner: all ok → "All systems operational"; any failure → amber "Something's not answering" (copy notes it may be the visitor's network) + fires a `status_check_failed` analytics event. Incident log is an honest empty state ("history begins June 2026") — write a public postmortem there if an incident happens. Has a "run checks again" button. **Contains the second copy of `SCRIPT_URL`** (see forms-and-data.md).
- **`privacy.html`** — UK/EEA-aware policy; **GrowthKit AI is the data controller**. 19 numbered sections (Who we are, Scope, Information collected, Use, Legal basis (UK/EEA), Sharing, Cookies & analytics, International transfers, Retention, Security, Rights, Children, Third-party links, Disclaimers, Liability, Indemnification, Changes, Governing law, Contact) with a sticky TOC. Dark mode is full manifesto-grade: hero document register (pulsing LED + blinking version cursor), neon section-eyebrow dashes, log-entry scan-wash on every section (padding offset by negative margins so the text column matches light), terminal-card TOC with hover-lit index numbers.
- **`terms.html`** — numbered ToS sections (agreement, definitions, eligibility, waitlist/pilots/beta, acceptable use, accounts, IP, fees, third parties, confidentiality, liability, termination, governing law). Dark mode is full manifesto-grade: giant neon-wireframe `§` ghost behind the hero (one dark-only `aria-hidden` span, hidden in light), blinking caret on the version stamp + TOC label, CRT sweep over the terminal-card TOC, section scan-wash hovers.
- **`specimen.html`** — **the sample deliverable** ("Specimen №02 — this is the specimen"): a full GrowthKit teardown of **Crewline, a fictional company** in field-service software for independent HVAC contractors. Subject-brief plate with an honesty note (fictional subject, real method, illustrative numbers; competitors are invented composites) → hand-built SVG market map (11 vendors, axes = workflow depth × price/seat, dashed gap zone; dots self-plot on reveal; SVG re-inks via CSS classes in dark mode) → competitor teardown table (3 of 6 rows visible) → gap analysis (2 of 4 cards, animated score meters) → 90-day plan (plays 01–03 visible, 04–14 redacted). Redaction = blurred placeholder content (`filter: blur(7px)` + `aria-hidden` + `user-select:none` + `pointer-events:none`) clipped by `overflow:hidden` with `box-shadow: none !important` inside (un-clipped blurred shadows caused the old "weird boxes" glitch) under a radial veil + "join the waitlist" overlay card. **Analysis copy is placeholder-grade — content refinement is a Cowork job.**
- **`pricing.html`** — **the public source of truth for pricing.** Three plan cards: Pilot $0 (invite-only from waitlist) / Basic $30/mo / **Premium Agentic $200/mo (featured)** — plus a dashed "1-to-1 partner work, direct contact" strip, plain-language small print (beta, cancel anytime, USD), CTA to /specimen. Head carries **Product JSON-LD with three Offers** (`UnitPriceSpecification`, P1M) — **update the schema whenever prices change**, not just the visible cards, and keep the index FAQ in sync.
- **`onboarding.html`** — **structured client intake** (deliverable pipeline, Step 2). `noindex`; has a clean URL (`/onboarding`) but is deliberately NOT in the sitemap — the footer "Become a client" link is its intended public entry point. Form: company, website, contact, work email, stage, market description, known competitors, ICP, notes. POSTs to its own Apps Script — see forms-and-data.md (note: its honeypot is `fax`, NOT `company`, and **its `SCRIPT_URL` is currently EMPTY**). Emits `onboarding_submitted` / `onboarding_error` events.
- **The tool ("GrowthKit Live")** — the streaming Claude Opus 4.8 growth read (positioning + competitor-gap cards + play cards + copy/share/PDF; shared `advisor.css`/`advisor.js`; POSTs to `/api/advise`). **As of 2026-06-12 it lives behind login at `/four`** — see the auth section below and [`docs/advisor.md`](advisor.md). The standalone `advisor.html` page was **deleted** (`/advisor` → redirects to `/four`).
- **`404.html`** — minimalist error page, `noindex, follow`, links to home + waitlist. No footer (intentional). Dark mode: giant neon-outline ghost "404" + blinking cursor after "Error · 404". Loads theme.css (it didn't until 2026-06-10 — dark mode silently no-op'd).

## Auth / app pages (noindex, out of sitemap — see [`docs/auth.md`](auth.md))

- **`login.html`** (`/login`) — email + password + "Continue with Google", remember-me, forgot-password link. On success → `/four`.
- **`signup.html`** (`/signup`) — email + password (8+) + Google; with email confirmation on, shows a "check your email" state. On success → `/four`.
- **`reset.html`** (`/reset`) — password reset: request-a-link form, and (when arriving from the emailed link) a set-new-password form.
- **`four.html`** (`/four`) — **the gated product**: after login this IS the GrowthKit Live tool (reuses `advisor.css`/`advisor.js`, `data-gk-full`). Onboarding is an **adaptive multi-step wizard** (redesigned 2026-07-08; multiple-choice cards/chips that branch on industry + stage, a fast-track shortcut, and a premium animated loading sequence — see [`docs/advisor.md`](advisor.md)), plus a **"Your reads"** history panel loaded from the user's Supabase `reads` table (click a past read to re-view it). Between the console and the reads panel sits a static **"Integrated with · Coming soon"** strip (`.integ-soon`, styles in `auth.css`, added 2026-07-09) — the same 8 monochrome brand logos as the landing strip (inline `#gkl-*` sprite), signalling planned integrations. Redirects to `/login` if not signed in; top bar shows the signed-in email + Sign out.
- All four: `noindex`, no footer, minimal top bar; Supabase Auth via CDN; shared `auth.css` + `auth.js` + `auth-config.js`. **Sign-in is inactive until Supabase keys are pasted into `auth-config.js`** (pages show a "not configured" notice until then).
